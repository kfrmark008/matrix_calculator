# Matrix Calculator

A C++ command-line tool for adding and subtracting two matrices with matching dimensions.

## Skills demonstrated
- Two-dimensional vectors
- Nested loops and function decomposition
- Matrix arithmetic and dimension validation

## Build and run
```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o matrix_calculator
./matrix_calculator
```

The program accepts dimensions from 1 to 10, then reads both matrices and prints their sum and difference.

## Possible extensions
Add matrix multiplication, transpose, identity matrices, and determinant calculation for square matrices.
